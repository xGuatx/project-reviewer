# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-04

### Added

- Initial release
- `scan` command for security scanning and credential detection
- `classify` command for project classification
- `questionnaire` command for interactive project decisions
- `plan` command for action plan generation
- `verify` command for coherence and pre-publish verification
- `execute` command for action plan execution
- `clean-ascii` command for non-ASCII character removal
- Configuration support via JSON files
- Project mappings for renames, splits, and merges
- Multiple output formats: text, JSON, markdown
- Dry-run mode for all commands
- Verbose mode for debugging
